# INF-PROF — Introduction to Python for Data Science

This repository contains the student material for the **INF-PROF** course.

Course material is published progressively throughout the semester. Corrections
and annotated versions may be released after the corresponding sessions.

## Course outline

The course is organized around four main blocks:

1. **Introduction to Python**
2. **Data manipulation with pandas**
3. **Data visualization**
4. **Final project**

Depending on the session, this repository may contain:

- lecture notebooks;
- practical work;
- additional resources;
- files required for the final project.

Links to the online sessions and administrative information are available on Amétice.

## Getting the course material

The repository can be cloned with:

```bash
git clone https://github.com/lrnv/inf-prof.git
```

To update an existing local copy:

```bash
git pull
```

## Working environment

The course mainly uses **Python** and Jupyter notebooks.

You therefore need a Python environment capable of opening and running `.ipynb`
files. **Visual Studio Code** with the Python and Jupyter extensions is a suitable
setup.

Required Python packages will be specified progressively in the course material.

**Tip:** you could go to [google colab](https://colab.research.google.com/) to run notebooks online instead of locally.
